# Feature brief guidance

Files in this directory describe high-level product vision and feature direction. Keep them durable and concise; do not use them as detailed live specifications of current functionality.

Keep Deliverable-local behavior, implementation scope, acceptance criteria, edge cases, and testing expectations with that Deliverable rather than in a feature brief. When a durable contract applies across multiple Deliverables, record it once in the relevant roadmap phase and have those Deliverables reference it.

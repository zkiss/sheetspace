# Hackathon issue log

**Branch-only tracking for `hackathon-bugfixes`. Remove this file before merging into `main`; it must not be included in the merge.**

## Fixed

1. **New sheets were saved but not rendered.** The backend omits default frame dimensions in its JSON response; the frontend now supplies the default width and height while decoding sheet frames.
2. **Formula references and paths obscured the formula inspection panel.** Reference tokens in the white panel now receive distinct colors, reference paths appear when hovering a token, and the toolbar can show or hide all paths without rendering a separate dark reference list.
3. **Data-model formulas need same-row property references.** Model formulas now support `@property` and `@'Property name'` as same-row references. Existing relative column references such as `@A[1]` and explicit cross-sheet references such as `@Sheet!A[1]` remain supported.
4. **Saving a newly created data model failed with `invalid-model-lifecycle`.** Backend model-lifecycle reconciliation now permits changes to data-model membership while continuing to require an unchanged sheet membership.
5. **Reference paths disappeared when a target was outside the workspace viewport.** Reference paths now terminate at the workspace edge with a colored marker pointing toward an off-screen target.
6. **The command palette listed every sheet as a top-level command.** It now has one `Go to sheet…` command that opens a searchable, narrowing list of sheet names.
7. **Reference navigation was a short one-speed transition that framed sheets opportunistically.** It now flies over with an ease-in-out motion at the destination sheet's natural scale, retaining the current pan unless that zoom would hide the target.
   - **Off-screen arrival jumped instantly and bounced.** A live-browser trace confirmed that cell focus and `scrollIntoView()` were scrolling the workspace's hidden overflow independently of the animated camera. Grid focus now prevents native scrolling, cell reveal only scrolls the sheet body, and workspace overflow is clipped rather than scrollable. Browser inspections of both `Go to sheet → first` and Ctrl-clicking the reference from `aaa` showed gradual camera movement with workspace scroll remaining zero.
   - **The source sheet disappeared at the start of a flyover.** Frame virtualization now follows the browser's displayed camera transform throughout the animation rather than the final destination viewport. Browser inspections confirmed the source remains mounted while visible and is culled only after leaving the overscan area, for both sheet-picker and reference-click navigation.
8. **Formula references did not follow model-defined column names.** On a model-bound sheet, unquoted indexed references such as `@'Soma Data'!sum[1]` now prefer the attached model's property names over spreadsheet column letters. The editor, storage conversion, and model-template binding share that resolution rule. Ordinary sheets retain letter-based addressing. A read-only browser inspection confirmed the reported formula resolves to the `sum` property and evaluates to `-5` using the live workbook.
9. **Reference paths disappeared for miniature, non-interactive sheets.** Overview-mode sheets now anchor reference paths to their visible frame and use a dashed frame outline instead of a cell highlight. This works for both source and target sheets; off-screen miniatures retain edge pointers. Browser inspection confirmed paths remain visible after zooming the source into overview mode.
10. **Reference lines crossed through source and target centers.** Lines now connect the facing rectangle edges for cells, ranges, and miniature sheet frames; off-screen paths also start at the source edge. Browser inspection confirmed visible target endpoints lie on their highlight outline.
11. **Simple property names acquired unnecessary quotes during formula editing.** Formula display and property completions now leave identifier-like names unquoted, preserving `@sheet!property[1]`. Names with spaces or punctuation remain quoted and apostrophes are escaped. A read-only browser inspection confirmed storage/display round-tripping preserves `@'Soma Data'!sum[1]` and completion inserts `@sum`.
12. **Formula autocomplete hijacked formatting and moved the editor around.** Automatic function suggestions now require a name prefix and only open during typing, not caret selection or whitespace. Ctrl+Space explicitly requests suggestions. Enter inserts a newline unless the user has selected a suggestion with the arrow keys; Shift+Enter always inserts a newline, Tab/Shift+Tab indent/outdent, and Ctrl/Cmd+Enter always applies. Suggestions float near the textarea caret instead of adding layout rows. Live browser interaction confirmed newline, whitespace, indentation, explicit acceptance, and Escape behavior without changing workbook data.
13. **Reference hover values moved the hovered token and flickered.** Hover values now render in a fixed, non-interactive tooltip overlay. Browser inspection confirmed both the reference token and textarea retain their positions while the tooltip stays visible.
14. **Cell and formula editing used separate surfaces.** F2 now opens the shared formula-aware textbox directly at the cell in light mode; another F2 expands it over the sheet body with a stronger border and Format/Cancel/Apply buttons. F2 toggles back without replacing the textbox or losing the draft/caret. Light Enter/Tab commit and navigate, while heavy Enter/Tab support multiline formatting. Esc cancels only light editing; Ctrl/Cmd+Enter applies and Ctrl/Cmd+Esc cancels either mode. The separate floating editor and duplicate formula preview are removed; highlighting and reference hover live in the textbox. Browser interaction confirmed modes, helpers, formatting, cancellation, and navigation with writes intercepted, and production TypeScript checks pass. Tests remain untouched.
15. **Canvas dragging lagged behind navigation animations.** Drag movement now paints the camera once per animation frame without rerendering unchanged tables, and only publishes intermediate viewport state when the mounted sheet set changes. Release commits the exact final viewport. The background grid is translated as a separate layer rather than repainting its gradients for each pointer move. A 60-step live-browser drag dropped from 188 to 15 React commits and about 4.0s to 0.5s of scripting in the same inspection. Browser checks confirmed exact drag displacement, grid alignment, interruption of a flyover, and zooming after release; production TypeScript checks pass. Tests remain untouched.
16. **The command palette was hard to scan and lacked shortcuts.** The palette now has readable full-width rows, a highlighted selection, muted right-aligned shortcuts, clear unavailable reasons, and keyboard guidance. Every top-level command has a working shortcut; Alt+Shift+S opens sheet search, Alt+Shift+P opens property search, and Alt+Shift+R opens the row picker. Browser checks confirmed the new shortcuts, filtering, and keyboard selection; production TypeScript checks pass. Tests remain untouched.
17. **Go to row used a native browser prompt.** It now opens an in-app palette input with the current sheet name, valid row range, and inline validation. Browser checks confirmed both command and shortcut entry, invalid input feedback, Escape cancellation, and navigation while retaining the current column.
18. **Back/forward and undo/redo used inconsistent navigation motion and mounting.** Viewport restoration and highlight reveals now share the sheet-navigation flyover, with destination sheets pinned during history restoration and undo/redo feedback. Undo/redo reveals no longer retarget mid-flight after measurement. Browser checks confirmed animated back/forward, interruptible movement, and off-screen undo reveal with writes intercepted; production TypeScript checks pass. Tests remain untouched.
19. **Selection jumped abruptly between sheets.** The previous cell selection fades out while the new sheet's selected cell fades in; the source sheet remains mounted briefly for the transition. Navigation no longer adds a separate background pulse, so mouse selection and Go to sheet use the same fade. Reduced-motion preferences suppress the fade. Tests remain untouched.
20. **Navigation zoom emphasized the wrong sheet.** Natural-scale navigation now zooms around the destination's top-left and moves it only as needed to fit the viewport, instead of scaling around the workspace origin. Browser inspection confirmed the target's top-left stays fixed when it fits; tests remain untouched.
21. **The data-model editor was too tall.** Properties now occupy compact rows with one type selector containing manual types and Function. Function properties are edited in place using the shared light/heavy formula editor and display an inferred result type when not editing; unknown inference is shown explicitly. Browser inspection confirmed inline editing, type inference, F2 mode switching, and cancellation without saving; production TypeScript checks pass. Tests remain untouched.
22. **Formula reference inspection was separate from editing.** Removed the formula float and brought its reference colors and hover paths into the cell formula editor, without the noisy reference-value tooltip. Ctrl/⌘-click follows a reference; F4 follows the reference under the caret. Navigation suspends the edit draft, and the Show references control remains available. Production TypeScript checks pass; tests remain untouched.
23. **The model formula editor's heavy mode hid its contents.** Heavy editing now overlays the model form with a properly sized formula surface, like the sheet editor, without expanding the dialog. Tests remain untouched.
24. **Subtraction immediately after a model property failed to parse.** The formula parser now recognizes the minus operator after an unquoted property without requiring a space, while retaining hyphenated canonical reference parsing. Tests remain untouched.
25. **Clickable reference paths were hard to discover.** Paths thicken and become more prominent as the pointer approaches, and their clickable stroke uses the pointer cursor. Tests remain untouched.
26. **Find usages included indirect dependents.** The command now shows only direct cell and model-property usages. Tests remain untouched.
27. **Zoom repeatedly redrew the workspace.** Wheel and pinch zoom now paint a frame-coalesced viewport preview, periodically publish for visibility and detail updates, and commit when the gesture settles. The background grid follows the preview. Tests remain untouched.
